This worklog summarizes my activities across the FCAJ program. The program ran for about 12 weeks, combining self-study of AWS Cloud & AI, hands-on labs, community activities, and a capstone project. Each week I set a learning goal, completed the related labs, and shared notes with the community.

The capstone thread running through the program was **publishing the FCAJ landing page on AWS** (S3 + CloudFront + Route 53 + ACM), documented in the [Workshop](../5-Workshop/) section.

| Week | Focus | Main activities |
| --- | --- | --- |
| 1 | Cloud foundations | AWS global infrastructure, IAM, billing, CLI setup |
| 2 | Compute & storage | EC2, S3, lifecycle, static hosting concepts |
| 3 | Networking | VPC, subnets, security groups, Route 53 basics |
| 4 | Content delivery | CloudFront, edge caching, TLS with ACM |
| 5 | Security | IAM policies, least privilege, OAC for S3 |
| 6 | Serverless | Lambda, CloudFront Functions, event-driven patterns |
| 7 | Data | Databases overview, data lakes, analytics intro |
| 8 | Generative AI | Amazon Bedrock, prompt basics, use cases |
| 9 | Automation | Infrastructure as code, deploy scripts, CI/CD |
| 10 | Capstone build | Deploy the FCAJ landing page end-to-end on AWS |
| 11 | Capstone polish | Custom domain, www redirect, verification, cost review |
| 12 | Wrap-up | Documentation, workshop report, community sharing |
